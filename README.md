## v1.38 更新内容

- 新增智能识别工作表功能：不再要求工作表必须命名为"成绩"和"科任教师"
  - 通过工作表名称和内容双重匹配自动识别
  - 显示置信度提示，告知操作者识别结果
  - 风险提示：非标准工作表名称时弹窗警告
- 修复UTF-8编码问题：中文内容不再乱码
- 修复密码弹窗逻辑：正常使用不弹窗，仅查看源码时要求密码
- 源码保护：禁止右键、F12、Ctrl+U、Ctrl+Shift+I/J、Ctrl+S
- 域名绑定：仅允许在 anbola.github.io 运行

## 功能说明

- 导入Excel成绩数据（智能识别工作表）
- 自动核算人均积分、A/B档分数线、积分比率
- 支持多科目核算
- 导出完整Excel报表
- 教师奖励和学生奖励统计
- 科任教师分组核算

## 部署方法

### 方法一：手动部署

1. 将 `deploy/` 文件夹中的所有文件上传到GitHub仓库
2. 在仓库 Settings → Pages 中选择 main 分支
3. 访问 `https://用户名.github.io/仓库名/`

### 方法二：使用构建脚本

1. 修改 `source_v1.38.html` 源代码
2. 运行 `python build_deploy.py` 生成加密部署版
3. 将 `deploy/` 文件夹内容上传到GitHub

## v1.40 更新内容

### 1. Logo 修复
- favicon 和页头校徽改用 `logo_.ico`
- 添加 `<link rel="icon">` 确保浏览器标签页显示图标

### 2. 导入模板姓名列锁定
- 模板定制中"姓名"列默认锁定（`locked: true`），防止误删

### 3. 班级名称按原样保留
- 导入模板中班级名是什么，核算表中就显示什么（不再去除"班"字）
- 例：导入"三年级1班" → 核算表显示"三年级1班"
- 教师带多班时合并名如"三年级1班三年级2班"
- 内部匹配使用 `normCls()` 去末尾"班"字进行教师表匹配，显示用原名

### 4. 核算参数配置界面紧凑化
- 改为 CSS Grid 多列自适应布局（`repeat(auto-fit, minmax(220px, 1fr))`）
- 考试名称占整行，其他参数三列并排
- 屏幕窄时自动转为单列

### 5. 成绩工作表增强
- **保留所有学生数据**：含不计成绩学生，保留原始"0"标注
- **新增备注列**：保存不计成绩原因等备注信息
- **删除年名后的"科任教师"列**：避免与各科目后的科任教师列重复
- **每个科目后新增一列科任教师**（默认隐藏）：检索本学科实际科任教师
- **身份证A列隐藏**：保护学生隐私信息
- **表头悬浮提示**：身份证A列和各科目教师列表头添加批注，说明数据已隐藏及解锁方法
- **标题行汇总提示**：标题单元格（A1）添加批注，汇总所有隐藏列及取消隐藏方法

### 6. 提示词文档重构
- 改为单列布局便于阅读
- 新增完整源代码展示
- 新增 GitHub Pages 部署详细教程

## 功能说明

- 导入Excel成绩数据（智能识别工作表）
- 自动核算人均积分、A/B档分数线、积分比率
- 支持多科目核算
- 导出完整Excel报表
- 教师奖励和学生奖励统计
- 科任教师分组核算

## 部署方法

### 方法一：手动部署

1. 将 `deploy/` 文件夹中的所有文件上传到GitHub仓库
2. 在仓库 Settings → Pages 中选择 main 分支
3. 访问 `https://用户名.github.io/仓库名/`

### 方法二：使用构建脚本

1. 修改 `source_v1.40.html` 源代码
2. 运行 `python build_deploy.py` 生成加密部署版
3. 将 `deploy/` 文件夹内容上传到GitHub
